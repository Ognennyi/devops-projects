# Simple Docker

Учебный проект по изучению Docker, Nginx, FastCGI и Docker Compose.

## Что реализовано

- Работа с готовым Docker-образом Nginx.
- Создание и управление контейнерами.
- Настройка Nginx и страницы `/status`.
- Разработка мини-сервера на C с использованием FastCGI.
- Создание собственного Docker-образа.
- Проверка безопасности образа с помощью Dockle.
- Запуск приложения через Docker Compose с отдельным контейнером Nginx.

## Структура проекта

- `src/server.c` — исходный код FastCGI-сервера.
- `src/Dockerfile` — основной Dockerfile приложения.
- `src/Dockerfile4` — вариант Dockerfile из предыдущего этапа работы.
- `src/docker-compose.yml` — конфигурация контейнеров.
- `src/nginx/` — настройки Nginx внутри приложения.
- `src/proxy/` — настройки обратного прокси.
- `src/otchet.md` — отчёт с результатами и скриншотами.

## Запуск

Для запуска необходимы Docker и Docker Compose.

Перейти в директорию проекта:

```bash
cd SimpleDocker/src
```

Собрать образы и запустить контейнеры:

```bash
docker compose up --build -d
```

После запуска приложение доступно по адресу:

http://localhost

Остановить контейнеры:

```bash
docker compose down
```

## Результат

Приложение состоит из двух контейнеров:

- **app** — FastCGI-сервер на C и Nginx.
- **proxy** — Nginx, который принимает HTTP-запросы и перенаправляет их в контейнер приложения.

Подробный процесс выполнения работы со скриншотами представлен в [отчёте](./src/otchet.md).
