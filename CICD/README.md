# CI/CD Pipeline

Учебный проект по настройке непрерывной интеграции и развёртывания приложения с помощью GitLab CI/CD.

## Функциональность

Пайплайн включает несколько этапов:

1. **Build** — компиляция C-программы через Makefile.
2. **Style** — проверка форматирования исходного кода с помощью clang-format.
3. **Test** — запуск автоматических тестов на Pytest.
4. **Notify** — отправка уведомлений о результатах CI в Telegram.
5. **Deploy** — ручное развёртывание программы на удалённый сервер через SSH и SCP с уведомлением о результате.

## Структура проекта

- `code-samples/` — исходный код C-программы и Makefile.
- `src/test.py` — автоматические тесты.
- `src/deploy.sh` — скрипт развёртывания.
- `src/notify.sh` — отправка Telegram-уведомлений.
- `materials/linters/` — настройки clang-format.
- `.gitlab-ci.yml` — конфигурация GitLab CI/CD.

## Локальный запуск

Для сборки необходимы GCC и Make.

```bash
cd CICD
make -C code-samples
mkdir -p build
cp code-samples/DO build/DO
```

Для запуска тестов необходимы Python и Pytest.

```bash
python -m pip install pytest
python -m pytest src/test.py -q
```

## Развёртывание

В учебном проекте развёртывание выполняется на отдельную виртуальную машину по SSH. Адрес сервера указан в `src/deploy.sh`.

Для отправки уведомлений используется Telegram Bot API. Токен бота и ID чата хранятся отдельно от исходного кода.

Конфигурация `.gitlab-ci.yml` создана для исходного отдельного GitLab-проекта. При использовании в общем репозитории нужно адаптировать пути и настроить GitLab Runner.
