# DevOps Projects

Репозиторий с учебными проектами по DevOps. В проектах изучал контейнеризацию приложений, настройку веб-серверов и автоматизацию сборки, тестирования и развёртывания.

## Проекты

### 1. [CI/CD](./CICD)

Настройка CI/CD-пайплайна в GitLab для автоматизации разработки.

Реализовано:
- Сборка C-программы с помощью Makefile.
- Проверка стиля кода через clang-format.
- Автоматическое тестирование с Pytest.
- Развёртывание приложения на удалённом сервере через SSH и SCP.
- Уведомления о результатах пайплайна в Telegram.

**Технологии:** GitLab CI/CD, Linux, Bash, C, Python, Pytest, SSH.

### 2. [Simple Docker](./SimpleDocker)

Работа с Docker, Nginx и контейнеризацией простого веб-сервера.

Реализовано:
- Работа с Docker-образами и контейнерами.
- Настройка Nginx.
- Разработка небольшого FastCGI-сервера на C.
- Создание собственного Docker-образа.
- Проверка безопасности образа с помощью Dockle.
- Запуск нескольких контейнеров через Docker Compose.

**Технологии:** Docker, Docker Compose, Nginx, FastCGI, C, Linux.


Подробные инструкции находятся в README каждого проекта.
